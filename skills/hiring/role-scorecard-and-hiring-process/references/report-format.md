# 報告書形式

## 1. 役割と判断

期待成果、能力、must、重み、最低評価を示し、候補者ごとに `advance`、`hold`、`do_not_advance` を示す。

## 2. 証拠とゲート

加重評価、証拠区分、失敗must、不明must、工程ゲート、評価者間不一致を並べる。スコアと適格性を混ぜない。

## 3. 感度と反証

重み変更による順位、実績主張への反証、ワークサンプル、追加質問、リファレンスで確認する事項を示す。

## 4. 次の行動と権限

追加検証の担当者、期限、合格・停止条件を置く。候補者連絡、面接、不採用、照会、オファー、報酬提示は明示承認後だけ実行する。
