# 比較メモ形式

利用者の言語で、次の順番にまとめる。金額は入力通貨と比較期間を各表の近くに示す。

1. **意思決定の要約**: 対象業務、決定期限、比較期間、通貨、現状維持の制約。経済順位だけで採択しないことを明記する。
2. **比較表**: 各候補の一時費用、期あたり経常費用、期間総費用、稼働後の期あたり定量便益、期間総定量便益、正味定量効果、回収期間。便益には売上・費用回避・損失回避の区分と根拠状態を付ける。
3. **実行適合性**: 仕事量・変動性、戦略的重要性、機密性、品質管理、立ち上がり時間、可逆性、社内学習価値、管理負荷を候補間で並べ、許容できない条件を先に除外する。
4. **悲観ケースと不明点**: 悲観ケースの明示的な倍率と結果を記し、不明な見積・便益・品質・責任分界は別の箇条書きにする。悲観値を不明値の代わりに使わない。
5. **条件付きの選択**: 「この条件なら候補A」の形で、成功指標、品質またはセキュリティのゲート、失敗時の停止・切替条件、再判断日を示す。未価格化の価値を結論の理由に含めるときは金額表の外で明記する。
6. **承認前の実行準備**: 実行する候補がある場合だけ、相手、金額・条件、アクセス範囲、不可逆性を確認できる準備事項を示す。応募、連絡、契約、発注、購入、導入には進まず、その外部行為の直前に明示承認を求める。
