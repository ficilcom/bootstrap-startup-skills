# 最初の採用の資金余力報告書

計算器の出力と根拠台帳を統合し、次の順序で利用者の言語による報告書を作る。`indeterminate` の場合は、不足情報を先に示し、採用可否や開始月を数値で断定しない。

```markdown
# 最初の採用の資金余力

## 意思決定サマリー
- 基準日・通貨・予測期間: [値]
- 判定: [hire_now / conditional / defer / unaffordable / indeterminate]
- 最短採用可能時期: [月・日付、または期間内になし]
- 今決めること: [採用開始、条件確認、延期、または見送り]

## 現金とデータ品質
- 利用可能現金 / 最低現金バッファ: [値]
- confirmed / reported / estimated / unknown: [判断を変える項目と根拠]

## シナリオ比較
| シナリオ | 開始月 | 判定 | 最低現金 | バッファ割れ | 現金不足 | 雇用総コスト | 便益回収月 |
| --- | ---: | --- | ---: | --- | --- | ---: | --- |
| base | [値] | [値] | [値] | [月 / 期間内なし] | [月 / 期間内なし] | [値] | [月 / 期間外] |
| downside | [値] | [値] | [値] | [月 / 期間内なし] | [月 / 期間内なし] | [値] | [月 / 期間外] |
| delayed | [値] | [値] | [値] | [月 / 期間内なし] | [月 / 期間内なし] | [値] | [月 / 期間外] |

## 雇用総コストと便益
- 月額給与、会社負担、福利厚生、ソフト・設備、管理時間: [内訳]
- 一時費用（採用、設備、オンボーディング、偶発費用）: [内訳]
- 生産性立上がりコストと便益の月別前提: [根拠・時期]

## 採用前後の現金とランウェイ
- [最も厳しい月について、採用前期末現金、採用の純現金増減、採用後期末現金、バッファ差]
- [最低現金、バッファ割れ月、現金不足月。期間外は「予測期間内になし」]

## 実行条件と撤退条件
- 実行条件: [条件付きの場合は不足額、根拠、期限]
- 撤退条件: [バッファ、費用上限、便益立上がり、法令・契約確認]

## 専門家確認と権限境界
- [法域依存の税・社会保険・労働法について、確認日・一次情報・必要な専門家]
- 求人、連絡、オファー、契約、支払、終了手続は、各実行直前に利用者の明示承認を得る。
```

採用の総コストと便益を相殺して一つの値だけにせず、両方を示す。`more_than_horizon` を「安全」「無限」と表現しない。計算結果は入力仮定に基づく運営見通しであり、雇用・税務・法務・会計の専門判断ではない。
