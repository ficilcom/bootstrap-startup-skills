# 最初の採用の資金余力インテーク

質問の前に、利用者が提出した銀行残高、直近の資金繰り、未払・回収予定、給与見積、福利厚生見積、求人・紹介契約、設備見積を読む。資料にある事実を再質問せず、採用可否を変え得る不足だけを確認する。氏名、住所、口座、個人番号、健康情報、候補者評価など不要な個人情報は収集・転記しない。

## 必要な事実

| 項目 | 必要な内容 | よくある誤り |
| --- | --- | --- |
| 現金とバッファ | 基準日、利用可能現金、最低維持残高 | 売掛金、使途制限資金、バッファを現金と混同する |
| 通常事業の現金 | 採用前の月次入金・出金と大口の月別調整 | 会計売上を回収予定額として扱う |
| 雇用の現金コスト | 年俸、事業主負担率、福利厚生、採用、一時設備、月額ソフト、オンボーディング、管理時間、偶発的一時費用 | 給与だけ、または年額と月額の混在 |
| 便益と時期 | 採用開始月、立上がり各月の増収・回避コストの現金便益 | 初月から満額の便益を置く |
| 不利ケース | 回収遅延、売上低下、コスト超過、便益遅延 | downside を base の単なる名称変更にする |
| 延期案 | 遅らせる月数、延期中の創業者負荷・機会損失 | 延期が無条件で現金を改善すると仮定する |

各数値は次のいずれかにする。

- `confirmed`: 資料または直接確認できる記録がある。
- `reported`: 利用者が示したが、資料確認していない。
- `estimated`: 将来の見積または仮定。
- `unknown`: 金額または時期が未解決。既知のゼロとは異なる。

事業主負担率や雇用義務が結論を左右する時は、法域、雇用区分、対象期間を確認する。税・社会保険・労働法の率を推測せず、現行の政府・公的機関の一次情報または有資格専門家へ確認する。
