# 採用可否の判断ルール

計算結果は資金面の条件であり、採用の戦略的価値を自動で決めない。採用する仕事、代替手段、創業者の負荷、需要、採用リードタイム、候補者の質を併記して判断する。

| 判定 | 資金上の条件 | 報告で明示すること |
| --- | --- | --- |
| `hire_now` | base と downside の双方で今月開始して月末バッファを維持 | 最低残高、採用便益の回収状況、残る見積前提 |
| `conditional` | base は今月開始可能だが downside は条件なしでバッファを維持しない | 不足する最大現金額、確認・資金改善・便益根拠などの開始前条件 |
| `defer` | 今月は適格でないが、期間内の後の開始月なら base と downside の双方でバッファを維持 | 最短開始月、延期までに達成すべき現金・受注・根拠条件、延期の事業不利益 |
| `unaffordable` | 期間内に base と downside の双方を満たす開始月がない | 最大資金ギャップ、採用以外の選択肢、採用を再検討する撤退条件 |
| `indeterminate` | 重要な現金、通常事業、または雇用コストが不明 | 不足情報、確認順序。数値判定を作らない |

`conditional` の「条件」は、例えば downside の不足額を埋める確認済み現金、契約済み回収、または保守的に再見積もった雇用コストである。未契約の資金調達や希望的な売上を条件達成済みとして扱わない。便益の回収月が期間外または不明でも、資金余力の判定と別に明示する。

採用を延期・中止する撤退条件は、少なくとも次を数値または観測可能な事実で定める。

- 採用前または採用後の予測で、base か downside が最低現金バッファを割る。
- 事業主負担、福利厚生、採用費、設備、オンボーディングの見積が未確認か、承認額を超える。
- 便益立上がりが、事前に選んだ月までに根拠ある水準へ達しない。
- 契約上・法令上の費用、通知期間、雇用区分が未確認で、想定外の義務を除外できない。

求人公開、候補者への連絡、オファー、雇用契約、支払、終了手続は、この判断の後にも各実行直前の明示承認が必要である。
