# インテークと判断方法

## 基準線

投資候補を入れる前の利用可能現金、最低現金バッファ、既存契約・給与・税・債務を含む月次純現金増減を固定する。売上目標をそのまま入金へ置き換えない。

## 候補の完全性

| 項目 | 確認内容 |
| --- | --- |
| 現金 | 初期費用、継続費、終了・移行費、基準・悲観便益 |
| 時期 | 支払月、便益開始、回収、判断期限 |
| 適合 | 必須ガードレール、四半期優先、任意、競合 |
| 可逆性 | 中止時間、解約・撤回費用、データ・顧客・人への影響 |
| 能力 | オーナー、実行時間、提供・営業・管理能力 |
| 依存 | 他施策、契約、採用、技術、顧客、規制 |
| 重複 | 他候補と同じ売上・削減・リスク低下を数えていないか |

## 判断

- `fund`: 両ケースでガードレールを守り、必須または優先戦略に整合し、実行能力がある。
- `stage`: 全額同時実行は弱いが、段階化で資金・学習・可逆性を改善できる。
- `test`: 結論を変える不明点を小さい費用と短い期間で判別できる。
- `defer`: 価値はあるが、資金、能力、依存、時期がまだ整わない。
- `reject`: 戦略と競合する、ガードレールを壊す、または根拠ある下振れで回復不能。

候補を採らない場合の機会費用も記述するが、裏付けのない金額へ変換しない。
