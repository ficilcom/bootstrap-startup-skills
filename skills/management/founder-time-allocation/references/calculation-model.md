# 計算モデル

## 主要式

- 時間配分率 = 活動時間 / 利用可能時間
- フォーカス得点 = 価値得点 × レバレッジ得点
- 過剰配分 = max(0, 配分時間 - 利用可能時間)
- 未配分 = max(0, 利用可能時間 - 配分時間)

得点は0〜5。創業者必須またはフォーカス得点16以上を保護候補、必須でなく委譲準備度3以上を委譲候補、価値・レバレッジが共に1以下を削減候補とする。時間が不明な活動があれば全体時間と回収可能時間を不確定にする。

## advanced契約

`analysis_mode: "advanced"` では、`observed_weeks`、`planning_horizon_weeks`、証拠区分付き `fragmentation_threshold_per_week` を置く。活動には頻度、観測期間中の切替回数、成果指標、`transfer` を追加する。

`transfer` は移管可能割合、初期引継ぎ時間、週次監督時間、受け手の週次空き時間、手順・品質・権限の準備状態を持つ。準備状態は `ready`、`partial`、`missing`、`unknown` とする。

- 週次活動時間 = 観測時間 / 観測週数
- 総回収時間 = 週次活動時間 × 移管可能割合 × 計画週数
- 純回収時間 = 総回収時間 - 初期引継ぎ時間 - 週次監督時間 × 計画週数
- 回収期間 = 初期引継ぎ時間 / (週次総回収時間 - 週次監督時間)

分母が0以下なら回収期間を算出しない。創業者必須、受け手能力不足、手順・品質・権限の未準備は移行ゲートとし、純回収時間が正でも `blocked` とする。純回収時間が0以下なら `uneconomic` とする。
