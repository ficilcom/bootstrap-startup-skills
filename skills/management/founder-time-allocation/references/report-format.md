# 報告書形式

## 1. 時間要約

観測期間、利用可能時間、配分・未配分・過剰配分、回収可能時間を示す。

## 2. 活動表

活動、成果、時間、配分率、創業者必須、価値、レバレッジ、委譲準備度、証拠を並べる。

## 3. 変更候補

`protect`、`consolidate`、`delegate`、`automate`、`reduce`、`stop test` ごとに根拠、受け手、品質条件、移行コスト、総/純回収時間、回収期間、移行ゲートを示す。

## 4. 2週間の実験

一度に少数の活動だけを変更し、回収時間、品質、顧客・チーム影響、戻す条件、再判断日を置く。

受け手能力不足、手順・品質・権限の未準備、計画期間内に回収できない候補を実行対象にしない。`analysis_quality` の不明点に観測方法と期限を置く。
