# 報告書形式

## 1. 案件判断

案件ごとに `continue`、`hold`、`exit`、`founder_intervention`、適格性、失敗must、未確認ゲートを示す。

## 2. 金額と時期

案件金額、入力確率、加重金額、受注予定日、次アクション日、期限超過、予測期間外を示す。加重順位と資格判断を混ぜない。

## 3. 反証と検証

顧客発言を裏付ける証拠、競合・予算・決裁・調達・商条件の反証、次に確認する事項、担当者、確認期限を置く。

## 4. 停止条件と権限

介入目的、成功条件、打ち切り日、撤退条件を明記する。CRM、顧客連絡、値引き、契約、失注処理は明示承認後だけ実行する。
