# 計算モデル

## 主要式

- WAPE = 過去の絶対予測誤差合計 / 過去実績合計
- 予測偏り率 = (過去予測合計 - 過去実績合計) / 過去実績合計
- ステージ加重額 = 現在案件額 × 過去受注率
- 下限・上限 = 現在案件額 × 各ステージの下限・上限率
- 目標差 = max(0, 目標 - 加重予測)

過去実績合計がゼロの場合、WAPEと偏り率は算出しない。必須ステージ入力が不明なら全体予測を不確定にする。

金額と数量は証拠状態付きオブジェクトで渡し、率は0〜1とする。`minimum_stage_sample` 未満は計算から除外せず、小標本フラグを付ける。
