# 計算モデル

## 主要式

- WAPE = 過去の絶対予測誤差合計 / 過去実績合計
- 予測偏り率 = (過去予測合計 - 過去実績合計) / 過去実績合計
- ステージ加重額 = 現在案件額 × 過去受注率
- 下限・上限 = 現在案件額 × 各ステージの下限・上限率
- 目標差 = max(0, 目標 - 加重予測)

過去実績合計がゼロの場合、WAPEと偏り率は算出しない。必須ステージ入力が不明なら全体予測を不確定にする。

金額と数量は証拠状態付きオブジェクトで渡し、率は0〜1とする。`minimum_stage_sample` 未満は計算から除外せず、小標本フラグを付ける。

## advanced契約

`analysis_mode: "advanced"` では `as_of_date`、`forecast_end_date`、ステージ別の `stage_age_limits_days`、匿名化した `opportunities` を置く。各案件にはID、顧客ID、ステージ、証拠区分付き金額、ステージ進入日、当初・現在の受注予定日、次アクション日をISO日付で渡す。

案件の加重額は既存のステージ率を使う。受注予定日が基準日から予測終了日までにある案件だけを `in_period_weighted_amount` へ含めるが、既存のステージ集計予測は上書きしない。

ステージごとに案件台帳の金額・件数と集計入力を照合し、差をフラグにする。顧客集中は案件金額の既知合計を分母とし、不明金額をゼロにしない。

履歴に `segment` と `regime` があれば組合せごとにWAPEと偏りを返す。定義やプロセスが異なるグループを合成して単一率を作らない。
