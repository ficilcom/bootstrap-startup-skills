# 報告書形式

## 1. 選定条件

目的、必須要件、失格条件、比較期間、利用量シナリオ、判断期限を示す。

## 2. 比較表

core/advanced/シナリオ別TCO、初期・運用・移行・退出費、要件ゲート、適合、信頼性、セキュリティ、サポート、契約、ロックイン、証拠を並べる。

## 3. 検証と交渉

不明点、代表業務での検証、データ出力確認、価格保護、SLA、解約通知、移行支援の交渉条件を示す。

## 4. 実行条件

選定・保留・除外候補、承認者、契約レビュー、移行計画、撤退条件を置く。

`conditional` は推奨ではなく、未検証要件を解消するまでの保留状態とする。`analysis_quality` の不明点を交渉事項と検証事項へ割り当てる。
