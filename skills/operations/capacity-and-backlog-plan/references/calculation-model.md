# 計算モデル

- 履行需要 = committed + backlog
- 潜在需要 = 履行需要 + qualified
- 累積履行不足 = max(0, 累積履行需要 − 累積能力)
- 介入追加能力 = 期間当たり能力 × 開始後の期間数
- 介入総費用 = 一時費用 + 期間費用 × 開始後の期間数

履行不足があれば受注ゲートは `closed`、履行は足りるが潜在需要で不足すれば `conditional`、どちらも足りれば `open` とする。不明値で判定できなければ `indeterminate` とする。

シナリオは利用者指定の需要係数と能力係数だけを適用する。介入・シナリオ結果はbase計画を書き換えない。
