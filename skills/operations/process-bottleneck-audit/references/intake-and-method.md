# インテークと診断方法

## 工程を揃える

| 項目 | 確認内容 |
| --- | --- |
| 単位 | 案件、注文、チケット、ロット等の一貫した完了単位 |
| 境界 | プロセスの開始・終了、各工程の入口・出口 |
| フロー | 期首仕掛り、期間流入、期間完了、期末仕掛り |
| 能力 | 利用可能分、単位当たり正味作業分、担当・設備 |
| 遅延 | 待ち時間、阻害件数、依存先、承認、バッチ |
| 品質 | 手戻り、再処理、廃棄、初回合格の定義 |
| 需要 | 同期間に完了が必要な単位数、納期、優先区分 |

工程を飛ばす例外、差し戻し、並列処理、優先案件を別記する。単純な直列工程へ再構成できない場合は、同じ経路ごとに分析する。

## 原因検証

候補工程について次の順に確認する。

1. データ定義・期間・単位の不一致
2. 需要の到着変動とバッチ処理
3. 上流欠陥、情報不足、承認・顧客待ち
4. 純作業能力、切替、保守、スキル制約
5. 品質・手戻りと下流への影響

改善は、仕掛り上限、情報の入口条件、バッチ縮小、承認簡素化、手戻り原因除去、能力追加を比較する。最小実験に対象期間、期待完了数、品質・顧客ガードレール、停止条件を置く。
