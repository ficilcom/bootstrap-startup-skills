# インテークと出典

## 資料を先に確認する

質問より先に、次の資料の有無を確認する。無い資料は「無い」と記録し、推測で埋めない。

| 資料 | 取れる事実 |
| --- | --- |
| 前期の法人税・地方税・消費税の申告書控え | 決算期、課税事業者区分、計算方法、前期の納付額 |
| 中間申告の納付書、税務署からの通知 | 中間納付の有無、回数、金額、納期限 |
| 納付書（源泉所得税、住民税特別徴収） | 納付区分、対象期間、納期限、納期の特例の適用 |
| 特別徴収税額の決定通知書 | 住民税特別徴収の月額と対象年度 |
| 算定基礎届、月額変更届、保険料の納入告知書 | 社会保険料の月額、改定月、口座振替日 |
| 労働保険の年度更新申告書、納付書 | 労働保険料の年額、分割納付の回数と期日 |
| 口座振替の依頼書・通知 | 実際に資金が動く日（納期限と一致しない場合がある） |
| 給与計算の月次集計 | 源泉徴収税額と社会保険料の変動要因 |

収集しないもの: マイナンバー、口座番号、認証情報、個人別の給与明細、税理士との個別のやり取りの原文。

## 事業者プロフィール

プロフィールの各項目は、どの納付区分を想定するかだけを決める。金額も期日も決めない。

| 項目 | 値 | 想定への影響 |
| --- | --- | --- |
| `fiscal_year_end_month` | 1〜12 | 確定申告と中間申告の時期の起点。スクリプトは期日を導出しない |
| `consumption_tax_status` | `taxable` / `exempt` / `unknown` | `taxable` のとき消費税を想定する。`unknown` は想定にも想定外にも入れず、確認事項に回す |
| `consumption_tax_method` | `principle` / `simplified` / `not_applicable` / `unknown` | 金額の見積根拠。`exempt` と `principle`・`simplified` の組合せは矛盾として拒否する |
| `consumption_tax_interim` | `none` / `annual` / `quarterly` / `monthly` / `unknown` | 中間納付の回数。前期の納税額で決まるため、必ず一次情報で確認する |
| `corporate_tax_interim` | `none` / `one` / `unknown` | 法人税の中間申告の有無 |
| `has_employees` / `employee_count` | 真偽値 / 人数 | 従業員がいるのに人数が0の入力は矛盾として拒否する |
| `pays_withholdable_compensation` | 真偽値 | 役員報酬のみの場合も源泉徴収義務は生じる。従業員の有無とは別に持つ |
| `withholding_special_exception` | `none` / `semiannual` / `unknown` | 納期の特例の適用。適用の有無で納付の回数と月が大きく変わる |
| `resident_tax_special_collection` | `none` / `monthly` / `semiannual` / `unknown` | 特別徴収の納付頻度 |
| `social_insurance_enrolled` | 真偽値 | 社会保険料を想定するか |
| `labour_insurance_enrolled` | 真偽値 | 労働保険料を想定するか。従業員がいない場合の加入は矛盾として拒否する |

法人税と地方税は決算期がある以上必ず発生するため、常に想定に含める。`other_statutory` は上記のいずれにも当たらない法定納付の受け皿であり、想定にも想定外にも入れない。

## 納付区分と所管

| 区分 | 主な所管 | 確認すべき一次情報 |
| --- | --- | --- |
| `consumption_tax` | 税務署（国税庁） | 申告書控え、中間申告の通知、国税庁の該当ページ |
| `corporate_tax` | 税務署（国税庁） | 申告書控え、中間申告の通知 |
| `local_corporate_taxes` | 都道府県税事務所、市区町村 | 申告書控え、自治体の納期限の案内 |
| `withholding_income_tax` | 税務署（国税庁） | 納付書、納期の特例の承認通知 |
| `resident_tax_special_collection` | 市区町村 | 特別徴収税額の決定通知書 |
| `social_insurance` | 日本年金機構・健康保険組合 | 納入告知書、算定基礎届の結果、料率表 |
| `labour_insurance` | 労働局・労働基準監督署 | 年度更新の申告書、納付書 |
| `other_statutory` | 個別 | 該当する所管の公式情報 |

## 当日確認チェックリスト

金額と期日を入力に入れる前に、その日のうちに一次情報で次を確認する。過去の資料に書かれた期日や料率をそのまま使わない。

1. 納期限（土日祝の翌営業日への繰り延べを含む）と、口座振替の場合の実際の引落日。
2. 中間申告の要否、回数、金額の算定方法。前期の納税額に依存し、期によって変わる。
3. 社会保険料率と労働保険料率の改定の有無、改定の適用月。
4. 納期の特例（源泉所得税、住民税特別徴収）の承認状況と、対象期間の区切り。
5. 労働保険の年度更新の時期と、分割納付を選択している場合の各期の期日。
6. 消費税の課税事業者区分と計算方法が、当期も前期と同じかどうか。
7. 猶予・分割納付の制度は、要件と申請手続を伴う。適用可能かを推測せず、`deferrable` は確認できた事実だけを入れる。

## 情報区分と出典台帳

各納付について、金額の証拠状態（`confirmed` / `reported` / `estimated` / `unknown`）と、根拠となる公式情報を別々に記録する。

| 項目 | 内容 |
| --- | --- |
| `authority` | 所管（例: 国税庁、日本年金機構、○○市） |
| `document` | 資料名（例: 消費税の中間申告、特別徴収税額の決定通知書） |
| `url` | 確認したページ |
| `checked_on` | 確認した日。基準日より後の日付は拒否される |
| `version` | 様式や案内の版・改定日。記載がなければその旨を書く |

証拠状態の使い分け:

- `confirmed`: 納付書や決定通知に記載された確定額。
- `reported`: 利用者が実務上把握している額（例: 毎月の社会保険料の直近実績）。
- `estimated`: 前期実績や給与見込みからの概算。確定額と合算しない。
- `unknown`: 金額が決まっていない、または確認できていない。金額は `null` とする。

## 推測してはいけないもの

税額そのもの、料率、納期限、中間納付の要否と回数、納期の特例の可否、猶予・分割の適用可否、控除や特例の適用。これらはいずれも制度と個別事情に依存し、誤ると納付遅延や過少納付につながる。確認できない場合は `unknown` のまま進め、報告書に確認事項として残す。このスキルの出力は税務上の判定ではなく、税理士・社会保険労務士の確認を代替しない。
