# キャッシュ・ランウェイ報告書契約

スクリプト出力、資料台帳、前提、圧迫要因、対策候補を一つの報告書へ統合する。見出しの順序を保ち、数値が出せない場合は推測せず `indeterminate` の理由を記す。金額の通貨と基準日をすべての表で明確にする。

## 表示ルール

`quick` は判定の直近に「暫定」と表示し、月次平均では見えない週次支払集中を説明する。`indeterminate` はランウェイ月数や警戒日を作らず、`missing_inputs` と確認順序を示す。

`more_than_12_months` は「12か月超（以降は未評価）」と表示する。「無限」「安全」「資金は尽きない」に置き換えない。月数を示す場合は小数1桁へ丸め、期間末日ベースの推定であることを注記する。

シナリオ差は、最低残高、最大必要資金、バッファ割れ日、ゼロ割れ日のうち計算できるものを示す。片方が12か月超なら、存在しない日付差を作らず「baseは12か月内の割れなし」などと書く。

13週表は `detailed` の場合に全13週を出す。`quick` では13週表を作らず、「月次情報のみのため未作成」とし、月次期間表を示す。不明シナリオの数値表は作らない。

対策はスクリプトで再計算したものと、未計算の候補を分ける。未計算候補にはランウェイ延長月数を書かない。複数対策の単独効果を合算せず、組合せを再計算した場合だけ組合せ効果を示す。

## 注意事項

- この予測は入力と仮定に基づく運営計画であり、会計監査、支払能力、倒産、法務、税務、労務上の専門判断ではない。
- 給与、税金、債務、契約、規制、安全に関わる支出は、延期または不払いが可能と断定しない。
- 外部連絡、契約変更、解約、支払変更、送金、申請、取引は、実行直前に利用者の明示承認を得る。
- 口座番号、カード情報、認証情報、個人番号など不要な機微情報を報告書へ記載しない。
