# ランウェイ対策ラダー

対策は削減額だけでなく、現金効果が出る日、実行リードタイム、一時費用、売上・顧客・従業員・事業継続への影響で比較する。利用者の制約と依存関係を優先し、下の順番を機械的な命令にしない。

## 評価に必要な項目

各対策について次を埋める。金額または時期が不明ならモデルへ入れず、確認事項に残す。

| 項目 | 内容 |
| --- | --- |
| 判断期限 | リードタイムを考慮した最終決定日 |
| 現金有効日 | 残高へ効果が出始める日または期間 |
| 総現金効果 | 回収前倒し、支出削減、延期等による増加額 |
| 一時費用 | 違約金、移行費、専門家費用等 |
| 純現金効果 | 総現金効果から一時費用を引いた額 |
| 継続期間 | 一回限り、期限付き、継続の別 |
| 依存条件 | 契約、通知期間、承認、代替手段、実行担当 |
| 事業影響 | 売上、顧客、品質、従業員、継続性への影響 |
| 情報区分 | `confirmed`、`reported`、`estimated`、`unknown` |
| モデル結果 | バッファ日、ゼロ日、最低残高、必要資金の変化 |
| 利用者判断 | 採用、棄却、追加確認のいずれか |

## 1. 回収と運転資金

最初に、既に提供した価値の正当な回収と、タイミングの不整合を確認する。

- 期限超過の売掛金と請求漏れ
- 請求発行の遅れ
- 契約済みマイルストーンの達成・請求時期
- 利用者が選ぶ前払いまたは年払い条件
- 正当な返金・預り金・在庫・仕入条件の影響

顧客への督促、条件変更、請求送信は自動で行わない。関係悪化、値引き、返金義務、契約条件を考慮する。

## 2. 未使用・低効果の裁量支出

- 未使用または重複するソフトウェア
- 成果を確認できない広告・イベント・会員費
- 利用率の低い外部サービス
- 必要性が下がった出張、設備、裁量購入

解約日と現金効果日を分ける。年払い済みサービスは、解約しても直近の現金が増えない場合がある。返金、違約金、データ保持、セキュリティ、業務依存を確認する。

## 3. 未確定の採用・設備・プロジェクト

- オファー前の採用または開始日の延期
- 未発注の設備
- 回収時期が遠い新規プロジェクト
- 創業者が許容する範囲の段階的実施

契約済み、採用通知済み、または安全・顧客提供に必要な項目を、自由に延期できると扱わない。延期による売上機会、品質、創業者負荷の悪化も記録する。

## 4. ベンダー条件と固定費構造

- プラン変更、利用量調整、契約更新時の再交渉
- オフィス、物流、製造、専門サービスの構成変更
- 支払条件の協議
- 固定費から利用量連動費への移行

契約上可能か、相手の同意が必要か、通知期間、一時費用、供給停止リスクを確認する。合意のない一方的な支払延期を提案しない。

## 5. 事業へ影響する深い削減

- 人員、報酬、提供範囲、顧客サポートの変更
- 主要チャネルや製品開発の縮小
- 拠点、事業、製品の停止

法務、労務、契約、顧客、安全、レピュテーションへの影響が大きい。金額だけで順位付けせず、専門家確認、代替策、実行責任者、コミュニケーション計画を先に明らかにする。利用者の明示承認なしに外部へ連絡しない。

## 6. 資金調達との比較

運営対策だけでギャップを閉じられない、または利用者が資金調達を既に検討している場合に比較する。

- 必要額と必要時期
- 返済または希薄化の影響
- 実行までのリードタイム
- 成立しない場合の代替策
- 資金使途と、対策後のランウェイ

融資承認、投資実行、補助金採択を前提入金にしない。確度に応じて `reported`、`estimated`、`unknown` を使い、未契約の資金はdownsideで除外する。

## 優先順位

優先度は、少なくとも次の関係で判断する。

```text
実行価値
= 閾値割れ回避への寄与
+ 早く確実な現金効果
- 一時費用
- 売上・顧客・従業員・継続性への不利益
- 実行不能または法的・契約的不確実性
```

単一の合成点が判断を隠す場合は採点せず、依存関係を考慮して並べる。13週以内のバッファ割れを防ぐには、意思決定期限が先に来る対策を上位に置く。効果額が大きくても有効日が閾値割れ後なら、直近の解決策として扱わない。

給与、税金、債務返済、規制上の義務、契約上の支払、安全上必要な支出は「安全に延期できる削減候補」にしない。必要なら権威ある現行情報または有資格専門家による確認事項として示す。
