# 資金繰りインテーク

質問を始める前に、利用者が提出した銀行残高、入出金明細、売掛・買掛一覧、請求予定、給与・税・債務予定、予算、既存予測を読む。資料で確認できる事実を再質問せず、閾値の日付、警戒区分、資金不足額、または対策順位を変え得る不足だけを確認する。

## 最初に確定する事項

| 項目 | 必要な内容 | 注意点 |
| --- | --- | --- |
| 基準日 | 残高と予測の起点日 | すべての資料の更新日を併記する |
| 通貨 | 予測を作る単一通貨 | 換算前提がなければ通貨別に分ける |
| 総現金 | 現金・現金同等物 | 売掛金や未実行の融資を含めない |
| 使途制限資金 | 通常支払に使えない金額 | 最低現金バッファと混同しない |
| 最低現金バッファ | 利用者が維持したい運営余力 | 未指定なら理由とともに0を明示するか、`unknown` とする |
| 入金 | 実際の回収予定日と金額 | 請求日・売上計上日と区別する |
| 出金 | 実際の支払予定日と金額 | 税、給与、債務、年払い、一時費用を確認する |
| 継続前提 | 予測期間中の反復入出金 | 契約済みと希望的な成長を分ける |

口座番号、カード情報、認証情報、個人番号、本人確認書類番号、不要な従業員個人情報は収集・転記しない。資料名、対象期間、更新日、利用した項目だけを資料台帳に残す。

## モード選択

### `detailed`

直近13週間について、日付または週別の入出金が得られる場合に使う。次のいずれかがあれば優先する。

- 支払日または回収日の一覧
- 売掛金・買掛金の期日
- 給与、税、債務、年払いの予定
- 週別予算または銀行明細から作れる反復パターン

13週後から12か月の終端までは、月別の明示的な前提を使う。既知の一時入出金を平均化しない。

### `quick`

日付別の情報がなく、総現金、月間入金、月間出金、既知の一時入出金だけがある場合に使う。結果は必ず `provisional` とし、詳細モードへ移るために必要な資料を示す。

総現金、使途制限資金、最低現金バッファのいずれかが `unknown` なら、ランウェイを算出せず `indeterminate` とする。重要な入出金の金額が不明な場合も、影響を受けるシナリオを `indeterminate` にする。

## 情報区分

| 区分 | 意味 | 例 |
| --- | --- | --- |
| `confirmed` | 提出資料または直接確認できる記録がある | 基準日現在の銀行残高、署名済み契約の支払額 |
| `reported` | 利用者が申告したが資料確認していない | 口頭で示された入金予定 |
| `estimated` | 将来予測として置く仮定 | 更新率、平均月商、採用後の月額費用 |
| `unknown` | 金額または時期が未解決 | 税額未確定、契約条件未確認 |

金額ゼロは「発生しない」と明示的に分かる場合だけ使う。未入力、未確認、未確定をゼロにしない。JSONでは既知のゼロを `{"amount": 0, "evidence": "confirmed"}` などとし、不明は `{"amount": null, "evidence": "unknown"}` とする。

## 入出金の整理

各入出金に、少なくとも次を残す。

- 一意な識別子と短い名称
- 入金または出金
- 現金が動く日または期間
- 金額と情報区分
- 一回限りか反復か
- どのシナリオに含めるか
- 根拠資料または仮定

重複計上を避ける。例えば、個別請求を列挙した月に平均月商も加えない。消費税等を含む・含まない、給与と会社負担を含む・含まないなど、金額の境界を揃える。

## シナリオ

`base` は最も望ましいケースではなく、現時点で根拠のある中心見通しにする。次の不確実性が警戒日または対策を変え得る場合は `downside` を作る。

- 回収の遅延または未回収
- 継続売上の減少
- 一時費用の増加または前倒し
- 採用・設備・更新費用
- 為替換算、税額、返済額の不確実性

`upside` は採用、投資、削減の見送りなど具体的な判断に必要な場合だけ作る。単に楽観値を見せるためには作らない。

シナリオ間で同じ確認済み入出金は保持する。変える項目ごとに、変更理由、情報区分、金額、時期を記録する。

## 追加質問の優先順位

次の順で、結論を変え得る質問だけを行う。

1. 利用可能現金を確定する不足
2. 13週以内の給与、税、債務、契約支払、年払い
3. 大口入金の回収確度と日付
4. 最低現金バッファと意思決定に必要なリードタイム
5. 13週後の月次反復前提
6. 対策候補の金額、開始時期、一時費用、依存条件

専門家確認が必要な金額は推測せず、確認期限と、暫定シナリオへ与える影響を示す。
