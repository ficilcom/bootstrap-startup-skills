# インテークと判断方法

## 先に確認する資料

| 項目 | 確認内容 | 主な用途 |
| --- | --- | --- |
| 請求 | 匿名請求ID、顧客ID、発行日、期日、通貨、請求額 | 残高と年齢表 |
| 入金 | 入金日、金額、充当先、未充当金 | 未回収額の再構成 |
| 契約・検収 | 支払条件、検収条件、解約・相殺、請求先手続 | 遅延原因の区別 |
| 約束 | 約束日、金額、相手の役割、証拠状態 | 予定入金の根拠 |
| 紛争 | 理由、責任者、必要資料、解消期限 | 内部解決と督促の分離 |
| 資金 | 利用可能現金、最低バッファ、近日期限の支出 | 回収遅延の影響 |

同じ請求の重複、通貨混在、入金の未充当、税込・税抜の混在、クレジットノートを先に解消する。情報は `confirmed`、`reported`、`estimated`、`unknown` に分ける。

## 回収順序の決め方

候補を単一スコアへ潰さず、次を並べて判断する。

1. 最低現金バッファまたは支払期限への影響
2. 期限超過日数と金額、顧客別の合計露出
3. 支払約束の有無、約束日、約束不履行
4. 紛争、検収、請求誤り、購買手続などの阻害要因
5. 次の確認で不確実性を解消できる速さ
6. 顧客関係、契約、サービス提供への影響

アクションは「内部資料を直す」「相手先手続を確認する」「支払約束を取り直す」「責任者へエスカレーションする」を区別する。外部連絡は案まで作り、実行直前に承認を得る。
