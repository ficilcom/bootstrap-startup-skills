# インテークと比較方法

## 比較可能性

| 項目 | 固定する内容 |
| --- | --- |
| 顧客 | 新規有料顧客、再活性、契約、入金などの完了条件 |
| 費用 | メディア、制作、代理店、ツール、紹介料、割引の範囲 |
| 貢献 | 売上から控除する決済、提供、サポート等の変動費 |
| 期間 | 獲得コホート、観測期間、成熟条件、期間単位 |
| 帰属 | first/last touch、実験、自己申告等の規則と重複排除 |
| 能力 | 営業、オンボーディング、提供、在庫、サポートの上限 |

平均値は既存運用の説明、限界ケースは追加配分の判断に使う。追加費用と追加顧客が観測できない場合は、限界効率を推測せずテスト設計へ送る。

## 判断

- `増額候補`: 限界貢献が既知で回収条件内、能力・品質・計測の重大な制約がない。
- `維持`: 経済性は許容範囲だが、追加需要の根拠または能力が不足する。
- `縮小候補`: 整合した成熟データで限界貢献が負、または回収期限を超える。
- `最小検証`: 結論を変える入力が推定・不明で、小さい予算で判別できる。
- `測定修正`: 顧客定義、重複、期間、費用範囲が揃わず比較できない。

外部変更は提案に留め、実行前承認を得る。
