# 報告書形式

## 1. 判断

実験ごとに `run`、`hold`、`stop`、`scale`、`inconclusive`、`review` を示し、経済順位とは別欄にする。

## 2. 根拠

総費用、期待純価値、能力不足、必要・観測サンプル、観測指標、閾値、損失上限、証拠区分を並べる。

## 3. 反証とシナリオ

結果を覆す確率・貢献・費用、計測欠損、重複、季節性、ブランド・顧客リスクを示す。シナリオで順位や符号が変わる条件を明記する。

## 4. 次の行動

不明値ごとに最小の検証、担当者、再評価日、停止条件を置く。広告、予算、顧客接触、計測、本番実験の変更は明示承認後だけ実行する。
