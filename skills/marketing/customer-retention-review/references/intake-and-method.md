# インテークと診断方法

## 必要な範囲

| 項目 | 内容 |
| --- | --- |
| コホート | 開始時点の顧客集合、開始・終了日、成熟条件 |
| 売上 | 顧客別の開始・終了継続売上、単一通貨・期間 |
| 状態 | active / churned、縮小・拡張、更新期限 |
| 理由 | 顧客が述べた理由、内部推論、理由不明 |
| 先行証拠 | 利用、価値実現、サポート、支払、意思決定者、次の相互行為 |

## 診断

1. データ欠落、定義変更、契約開始・終了のタイミングを除外する。
2. 解約、縮小、更新停滞をセグメント・商品・契約・導入時期ごとに分ける。
3. 顧客が述べた理由と内部仮説を分離し、反証条件を置く。
4. 製品・提供・適格性・価格・契約・関係管理のどこで再発防止できるかを判断する。

更新シグナルは原因ではない。`usage_decline`、`unresolved_support`、`payment_issue`、`no_next_step`、`stakeholder_change` を観測証拠として使い、顧客確認前に結論を固定しない。
