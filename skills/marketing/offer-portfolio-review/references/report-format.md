# 報告書形式

## 1. 判断要約

判断日、対象期間、比較単位、主要な不明点、今回決めること・決めないことを示す。

## 2. 商品別表

売上、貢献利益、利益率、提供工数、1時間当たり貢献、能力消費、需要証拠、商品間関係、戦略適合、退出ゲートを並べる。

## 3. 判断候補

`grow`、`repair`、`test`、`bundle`、`hold`、`retire candidate` ごとに根拠、反証条件、顧客・契約影響を示す。

## 4. 実験と移行

検証する仮説、対象、期間、成功・停止条件、担当、再判断日を置く。終了候補には既存顧客の履行、代替、通知、返金・移行条件を添える。

シナリオで順位や能力不足が変わる場合は、変化を起こした価格、費用、時間の仮定を示す。`analysis_quality` の不明点を検証計画へ割り当てる。
